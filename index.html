오늘, 동네 친구
어때요?

심심할 때 가볍게 대화하고, 퇴근 후 산책이나 커피 한 잔을 함께할 가까운 동네 친구를 찾아보세요.

  • 데이팅이 아닌, 일상 대화 중심
  • 거리보다 관심사로 먼저 연결
  • 부담 없이 대화부터 시작
어떻게 쓰나요?
✔ 로그인 없이 바로 문의 가능 ✔ 1분 안에 연결 안내
심심할 때, 동네 친구 가까운 곳에서 관심사로 연결되는 일상 대화. 부담 없이 시작해요.
데이지는 이런 분께 잘 맞아요
퇴근 후, 가볍게

맥주 한 잔, 산책, 커피처럼 부담 없는 만남부터 시작해요.

새로운 동네 생활

이사/새로운 환경에서 동네 친구가 필요할 때 도움돼요.

관심사로 연결

주제(취미/산책/카페/운동)로 먼저 이야기하니까 훨씬 편해요.

어떻게 시작하나요?

아래 “채팅으로 문의”를 누르고, 동네/관심사를 알려주면 안내해드려요.

  • 1
    동네 알려주기 예: 강남 / 성수 / 잠실 / 홍대
  • 2
    관심사 선택 예: 산책 / 카페 / 맥주 / 운동 / 전시
  • 3
    안내 받고 시작 필요한 정보만 확인 후 연결을 도와드려요.
※ 공개하고 싶지 않은 로그인/앱 화면은 보여줄 필요 없어요.

무엇을 문의하면 되나요?
